Looklook desktop 1.59.0: DSH gets the chat view, @-mentioning the bot in a group now answers you privately, and while Looklook is open you get in-app reminders instead of extra Feishu notifications.

- New: DSH now uses Looklook's chat view by default: images, steering, stop, approvals, answering questions, plan mode and model switching, with several sessions at once. A little pixel fish in the corner of every chat reacts to what the AI is doing; you can hide it.
- New: Switch permissions in Codex chats (read-only, default, full access; Shift+Tab cycles). Type @ in the Codex and Claude input to reference project files.
- New: While Codex is replying, Tab queues your message for after this turn (Enter still steers).
- New: Chats render mermaid diagrams; very long messages start collapsed; each reply's steps fold into one block that collapses when done.
- New: Running claude, codex or dsh by hand in a terminal switches the session to that tool's icon (on phones too) and names it after the conversation; plain terminals show whether a command is running.
- New: Background sessions you haven't opened for a while are stopped automatically (7 days by default; busy ones are left alone; change it in Settings). "Clean up background sessions" in the session list menu lets you pick and stop them after confirming. AI sessions continue the same conversation next time.
- Changed: When you @ the bot in someone else's group, the group message only gets a reaction; the project picker, answers and approvals go to your private chat, so the group can't see your projects or what ran. To tell the group, tap "Reply to them" on the answer card. Turn on "Answer in the group" for the old behavior.
- New: "One group per project": a session's notifications go to its project's Feishu group (created automatically), one topic per session; replying in the topic talks to that session.
- New: "Don't send while Looklook is open" (on by default): while you're using Looklook, Feishu and other channels are held back and you get an in-app reminder instead; once you leave they're sent as usual.
- Improved: The notification settings are reorganized: a summary at the top of how notifications work and what's set up, and a separate card for the Feishu bot explaining how to use it and group privacy.
- Improved: Tap the latency badge on a terminal to see the connection type, packet loss and both addresses; high loss shows on the badge itself.
- Improved: On phones, the "Me" and "Tools" menus have a title and close button, close with a swipe down or by tapping the tab again, and no longer close when you scroll them.
- Improved: Usage stats split Claude Code accounts and third-party APIs and price each by the provider actually used; Codex providers you defined yourself are recognized; there's a new "by account / API" table.
- Improved: Images open in a viewer on the page with zoom and download, instead of a new window.
- Fixed: The macOS app title kept stacking "●(1)".
- Fixed: In the macOS app's terminal, Chinese punctuation like "？" needed two key presses.
- Fixed: /resume in Codex and Claude chats didn't list all earlier conversations.
- Fixed: Large downloads failed partway when opened remotely.
- Fixed: A session sometimes showed the name of another session in the same folder.
- Fixed: Adding an official Claude account opened a browser on the computer running Looklook by itself.
- Fixed: Typing right after switching sessions went into the previous session's input; chat inputs capitalized the first letter.
- Fixed: When Looklook was started from a Claude Code terminal, Claude Code in its sessions didn't save transcripts.
