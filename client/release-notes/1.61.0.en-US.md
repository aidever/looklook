Looklook desktop 1.61.0: every page reworked to be understood at a glance — labelled icons, one-line hints, rarely used options folded away, one main button per row.

- Improved: icons in the left bar now carry their names (Sessions, Tasks, History, Files, SSH, Pages, System, AI, Settings), so there's no hovering to guess.
- Improved: each setting now has a single line of explanation; the long notes and rarely used options for remote routes, direct connection and access control fold into "Advanced", which opens by itself once you've set something there. The "local only" switch is now called "Use only this computer".
- Improved: SSH hosts are a list with one "Connect" button per row and test/edit/delete under "⋯"; local pages likewise have one "Open" button, with copy/share/pause/delete under "⋯", and running ports come first.
- Improved: on the AI assistant page one button installs the MCP connection into every AI assistant on this computer; AI tools now say what they do first, with function names after.
- Improved: no yellow safety notice when everything is safe, and only one top banner at a time; the session list expands only your recent projects and shows how many sessions are running in collapsed ones.
- Improved: when a terminal disconnects you only see the localized notice, without the extra English "Press ⏎ to Reconnect" overlay.
- Improved: e-mail addresses in organization names on the usage page are masked too.
