Looklook desktop 1.62.0: completion alerts no longer cover things or repeat; new usage stats; Feishu auto project groups.

- Improved: in-app "done / needs you / failed" alerts moved to the top right (below the top bar on phones), so they no longer cover the input box or header buttons. Several alerts merge into one card, one row per session; tap a row to open it, extra ones fold into "N more", and "Dismiss all" clears them.
- Fixed: sessions that finished earlier no longer show "done" again (also after a computer reconnects or the client restarts).
- Improved: redesigned usage stats, split by tool, account, model, project and session; compressed Codex session logs now count toward usage and past conversations.
- Improved: the Feishu bot creates project groups automatically (a DM session gets its own group); the #project syntax is gone; Feishu settings reorganized.
- Improved: sent messages show up in the chat right away; session icons tell terminal and chat sessions apart; project menus open on hover.
- Fixed: sub-agents no longer stay "running" after the quota runs out; when a Claude Code turn ends with background tasks still running, the session list says so.
- Fixed: unrecognized terminal screens are no longer treated as "waiting for your choice"; long titles no longer stretch the "Recent conversations" list; the auto-stop setting for background sessions no longer squeezes into one column on phones and now syncs across computers.
