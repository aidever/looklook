Looklook desktop 1.63.0: install chat pets from GitHub.

- New: AI assistant → Pets → Install from GitHub. Enter owner/repo or a repo link; if the repo holds several pets, they're listed so you can tick the ones you want. Installed pets link back to their repo.
- New: command line `looklook pet install owner/repo`; for multi-pet repos use `--pick` or `--all`.
- Fixed: setting descriptions no longer get squeezed into a one-character-wide column by buttons on tablets, landscape phones and narrow windows.
