Looklook desktop 1.63.1: window size remembered; no terminal flicker when switching sessions; install dsh-pet from GitHub.

- Fixed: the desktop app remembers its window size and position (including maximized) across restarts and updates.
- Fixed: switching sessions no longer redraws the whole terminal; hidden terminals are no longer shrunk and re-expanded.
- Fixed: in the macOS app, typing punctuation with a Chinese input method (Shift + symbol key) in the terminal no longer needs two presses.
- New: Install from GitHub also understands dsh-pet style repos (e.g. PC2005-cloud/dsh-pet, or your own pet kinds); only the config and animations are installed, not the repo's code or previews.
- Improved: large repos finish downloading on slow networks instead of being cut off.
- Fixed: the refresh button on the pets page always showed "Something went wrong".
- Fixed: opening DSH in the browser from the desktop app failed.
