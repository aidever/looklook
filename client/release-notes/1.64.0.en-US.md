Looklook desktop 1.64.0: Claude extra usage and Codex credits in Usage; install pets from files on your computer.

- New: Usage shows Claude extra usage, plus Codex credits and reset opportunities.
- New: Settings → Pets has "Choose from computer": pick a .llpet / .zip or an unpacked folder on the computer running Looklook, so large packs install even when opened remotely.
- Improved: uploading a pet pack on a phone no longer greys out .llpet files.
- Improved: the task panel lists background commands started before /clear or /new that are still running, with their command and run time, and can stop them.
- Fixed: after /resume switches conversations, the previous one is no longer marked as open in this session.
- Changed: pets only accept Looklook's own pet pack format; dsh-pet and Codex pets are no longer supported (dsh-pet installed from GitHub showed blank on Mac).
