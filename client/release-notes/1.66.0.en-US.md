Looklook desktop 1.66.0: edit and resend your chat messages; see how much CPU and memory each part of Looklook uses; pick a model, @ files and skills before a session starts; livelier multi-screen pets that deliver your alerts.

- New: edit & resend in Claude Code and Codex chats: change a message you sent and continue from there (everything after it is dropped; file changes are not reverted), optionally resending its images.
- New: a "Looklook usage" section on the System page shows CPU and memory for the main process, tmux, each session and helper processes, the largest/smallest/average session, and Looklook's total over time.
- New: the new-session page lets you pick the model and thinking level, @ reference files and pick skills like the chat input; the input follows the phone keyboard and the start button no longer gets pushed off screen.
- New: pets wander around and emote on their own; the desktop pet supports multiple screens and can walk or be dragged to another one; a pet in the browser and the desktop pet greet and chat with each other.
- New: with a pet on, alerts for other sessions (done, failed, waiting for you) come from the pet; click its bubble to open that session.
- New: pet lines are generated in the background with your choice of Claude Code / Codex model and thinking level, style presets or your own style, and a custom API using OpenAI Responses, OpenAI-compatible or Anthropic.
- Improved: one global pet, and settings take effect immediately; importing pets from other computers also works in "this computer only" mode.
- Improved: all dropdowns share one style and open as a bottom sheet on phones.
- Improved: Claude Code chat mode now uses the SDK protocol (with your own claude install) for new sessions.
- Improved: Feishu settings sync to all your computers, but by default only the computer Feishu was set up on sends its sessions' alerts; turn it on for others under notification rules.
- Fixed: remote file downloads resume where they stopped after a disconnect instead of failing; local downloads support resuming too.
- Fixed: on macOS, switching back to a terminal tab briefly showed a tiny terminal before filling the window.
- Fixed: "Queue for later" in a running Codex chat was hard to tap on phones.
- Fixed: forwarded bot cards and nested forwards in Feishu weren't recognized; replying in such a thread now starts a session instead of "can't find this topic's session".
- Fixed: Codex pet line generation failed with "env: node: No such file or directory".
- Fixed: a Codex chat could jump to a blank page mid-turn when the TUI in the terminal opened an empty conversation of its own.
- Fixed: Codex conversations copied with /fork and similar showed no earlier history in the chat.
- Fixed: output of /compact and similar commands showed raw terminal color codes in the chat.
- Improved: the open-source repository moved to github.com/aidever/looklook.
- Fixed: choosing "Type something." in a question stopped the turn; you can now type right in the dialog.
