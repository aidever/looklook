Looklook desktop 1.67.0: select text in a chat to comment on it, attach any file, switch model and thinking level mid-turn, a redesigned Files tab with multi-file download, and idle Codex chats now free their resources.

- New: select text in an AI reply to "Comment", "Ask about this" or copy it; the quote sits above the input, is sent with your next message and shows as a quote block in the history. On phones, quote from "Select text".
- New: attach any file in chats and on the new-session page (images are still shown to the AI; other files are passed by path), up to 10 files of 100 MB each; Claude Code reads attachments without asking for permission.
- New: multi-select questions in Codex: detected from the question, or switch any question to multi-select yourself.
- New: change the model and thinking level of a running Codex or Claude Code chat; when unchanged, the default level is shown.
- New: redesigned Files tab: sortable columns, type icons, filter, multi-select with batch actions, resizable preview, previous/next and keyboard navigation; on narrow screens time and size move under the name.
- New: download several files at once (up to 20 files / 2 GB) with progress, and a hint when the browser blocks multiple downloads.
- Improved: Codex chats idle for 30 minutes with nobody watching and no background commands are unloaded, freeing their MCP and other helper processes; reopening picks up where you left off.
- Improved: "Looklook usage" on the System page groups helper processes by program and shows how many Codex conversations are loaded; Codex background commands count toward their session, are listed separately and can be stopped.
- Improved: the thinking level is now at the top of the model menu on the new-session page instead of below a long list of models.
