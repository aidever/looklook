Looklook desktop 1.68.0: edit-and-resend now works like the desktop apps, files and sessions are linked, and videos and audio play in place.

- Improved: edit-and-resend has been reworked. Hover over one of your messages and click the pencil, edit it in place and press Enter to continue from there, even while the AI is still answering. After the client restarts, the conversation continues from the edited version instead of going back to the old one.
- New: files and sessions are linked. Reveal a file a session mentions, insert a file into the chat box, start a new session in a folder, and see Git changes marked in the file list.
- New: videos and audio in Files play in place; code files get syntax highlighting and line numbers.
- Improved: the Files and Git tabs keep their folder and position when you switch away or reload the page.
- Fixed: in narrow windows, the chat sometimes went blank while the AI was writing, as if it had stopped.
- Fixed: Markdown in "Preview" wasn't formatted.
- Fixed: new Claude chat-mode sessions never got a title and didn't show up in history.
- New: the default Claude account can be renamed or removed from the list (you stay signed in).
- Fixed: the new-session option bar was cut off on narrow screens; it now wraps.
