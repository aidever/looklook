Looklook desktop 1.70.0: Claude Code in chat mode now has the same features as Claude Code opened in a terminal.

- New: Claude in chat can use Artifacts to create pages on claude.ai and read comments on them. Before, only Claude Code opened in a terminal could.
- Fixed: typing /fast in chat said fast mode isn't available in the Agent SDK. You can now turn it on and off just like in a terminal, and if you turned it on in a terminal, it's on in chat too.
- Fixed: typing ultrathink in chat didn't make Claude think harder on that turn. It now works like in a terminal.
- Fixed: environment variables set in ~/.zshrc or ~/.bashrc (proxies, keys and so on) weren't visible to Claude in chat. They now are, like in a terminal.
