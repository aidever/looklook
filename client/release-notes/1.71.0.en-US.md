Looklook desktop 1.71.0: the desktop pet no longer gets in the way of your work.

- New: set the desktop pet's transparency (30% / 50% / 70%). It stays see-through so it doesn't cover what's behind it, and turns solid when you hover it.
- New: "Stay out of the way" for the desktop pet: clicks go straight through it, so you never hit it by accident. Hold Ctrl (Windows) or ⌥ Option (Mac) to grab it. Reminder bubbles stay clickable. This works with or without transparency.
- New: right-click the desktop pet for a menu to change transparency, size and "Stay out of the way", let it nap, or move it back to the chat page. The tray menu can also toggle the desktop pet and "Stay out of the way".
- Fixed: dragging or clicking the desktop pet stole focus from the window you were using (on Mac it also brought Looklook's main window to the front).
- Fixed: while chat mode waits for a usage limit to reset, it now continues automatically as soon as usage frees up early, instead of waiting for the reset time.
- Fixed: the context window size in usage was wrong when using a third-party API.
