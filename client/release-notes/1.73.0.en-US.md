Looklook desktop 1.73.0: Feishu and other notification setups now stay on the computer where you set them up and no longer sync to your other computers.

- Changed: Feishu, WeCom, DingTalk, Bark and the other notification channels, plus notification rules, are now stored only on the computer where you configured them. After updating, any notification setup that was synced over from another computer is removed automatically; the computer where you set it up keeps it.
- Changed: starting or continuing sessions from Feishu only uses projects and sessions on the computer with the Feishu setup. To get notifications from another computer, set it up there separately.
- Removed the "Send alerts for this computer's sessions" toggle, since the setup now lives on one computer only.
