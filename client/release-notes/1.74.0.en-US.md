Looklook desktop 1.74.0: a new Skills section in AI assistant lets you browse and delete the skills your AI tools installed on this computer, plus chat sharing, a project Run button, AI tool auto-updates and more.

- New: AI assistant → Skills lists the skills Claude Code, Codex, OpenCode and DSH installed on this computer. Filter by tool, open one to read its description, SKILL.md and files. Deleting moves it to a trash first — undo right away, and it is cleared after 7 days. Codex built-ins and plugin skills are view only. Works for your other computers remotely too.
- New: share a chat — all of it or picked messages — as a standalone web page, Markdown, or through the system share sheet, read only.
- New: project Run button (▶): set a command once, then run, stop and rerun it in the project terminal; compatible with Codex local environment actions.
- New: Claude Code, Codex and DSH check for updates, each with its own auto-update switch; updates install only when no session is using the tool.
- New: a "Recent" view in the session list, sorted by your last input instead of jumping with AI output.
- New: new chats preselect the model and reasoning effort you used last.
- New: model settings for context window and auto-compact via Claude Code's and Codex's official switches; the usage panel shows the window and the compaction point separately and follows your own settings.json / config.toml.
- New: an occasional faint one-line keyboard shortcut tip in empty space of the input box and session list.
- Improved: select-to-comment redesign — quoted text stays highlighted and numbered, comments can be edited or removed any time, and the action bar sits at the bottom of the chat.
- Improved: Codex / Claude chats started by other programs are grouped under "Other sources"; a failed Codex turn now shows why instead of looking blank.
- Improved: /doctor is in the chat command menu; after handing a chat to the terminal, questions and confirmations from the terminal also show in the chat page and can be answered from either side.
- Improved: the "away x min · N new" pill is replaced by a small dot on the "back to latest" button.
- Fixed: issues with send-now, input history, /new clearing, /resume getting mixed up, SSH sessions, and old sessions after updating.
- Fixed: handing a chat to the terminal while sending could leave two Claudes writing one chat, "Continue in terminal" stuck, or /new reverted.
- Fixed: cleaning up stray terminal sessions could hit other Looklook instances' sessions.
