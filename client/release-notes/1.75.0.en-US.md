Looklook desktop 1.75.0: a new Assistant (preview) — talk to one entry point and it finds the project and decides whether to start a new session or continue an existing one; plus fixes for stale queued messages and open pages running old code after a background update.

- New: Assistant (preview). The first icon in the rail: say what you want done and it finds the project, decides between a new session and continuing one, hands the work to Claude Code / Codex, and tells you when it is done. It blocks edits to project files while a session is already working there and asks you about anything uncertain. If it routed something wrong, change it to a new session or another session under "Routing". Requires Claude Code in chat mode on this computer.
- Fixed: after sending a message with images, the "Queued" box could keep showing a message that had already been sent, or bring back older messages.
- Fixed: after the computer auto-updates in the background, pages that were already open now switch to the new UI instead of running old code (which handed the chat to the terminal as soon as a session opened).
