看看电脑端 1.75.0：新增「助理」试用版——一个入口说话，它帮你找项目、决定新开还是接着原来的会话；另修了排队消息残留和后台更新后网页跑旧代码的问题。

- 新增：助理（试用版）。图标栏第一个入口，直接说要做什么，它会找到对应项目，决定新开会话还是接着原来的，把活交给 Claude Code / Codex，做完再告诉你。改项目文件时如果已有会话在干会先拦住，其余不确定的操作会问你。派错了可以在「去向」里改成新开或发给别的会话。需要这台电脑能用对话模式的 Claude Code。
- 修复：发了带图片的消息后，「排队中」里可能一直留着已经发出去的消息，还会冒出以前发过的旧消息。
- 修复：电脑在后台自动更新后，已经开着的网页会自动换成新版界面，不再跑旧代码（旧代码一打开会话就会把对话交给终端）。
