Looklook desktop 1.76.0: the assistant can run on Claude Code or Codex, has three permission modes, and takes your Feishu / Lark DMs.

- The assistant is no longer Claude-only: when you turn it on (or later from the assistant page header), pick whether it runs on Claude Code or Codex. The page, dispatching, agreements and routing bar work the same; each engine keeps its own conversation, and switching back continues where you left off.
- Three permission modes for the assistant: Read only, Ask first (default) and Hands-off. Hands-off runs commands and edits without asking, but dangerous commands still ask you; in a project where a session is working, the assistant may never edit files itself.
- The assistant's own permissions can no longer be bypassed: it can't be switched to "skip permissions / full access" from the chat, and commands that look read-only but actually write files or run programs now follow the permission mode.
- Feishu / Lark: with the assistant on, messages you DM the bot go to the assistant (turn it off under "Dispatch log" on the assistant page); when work you asked for in Feishu finishes or needs your answer, the assistant's update is pushed to Feishu too. Replying to a session card, /new and project groups still go straight to the session.
