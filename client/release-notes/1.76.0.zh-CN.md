看看电脑端 1.76.0：助理可以选用 Claude Code 或 Codex，权限模式三档可选，还能直接在飞书私聊里跟它说话。

- 助理不再只能用 Claude：开启时（或者以后在助理页页头）选底下用 Claude Code 还是 Codex。界面、派活、约定、去向条都一样；两种各是一段对话，换回来接着原来那段。
- 助理的权限模式可选三档：只看不动、动手前问（默认）、放手做。放手做时命令和改文件都不问，但危险命令照样问你；有会话正在干活的项目，哪一档都不让助理自己去改。
- 助理自己的权限不能再被绕过：对话里不能把它切到“跳过权限 / 完全访问”，一些看着只读、其实会写文件或执行命令的写法也会按权限模式先问你。
- 飞书联动：开了助理以后，飞书私聊机器人直接发的话交给助理（可以在助理页的“派活记录”里关掉）；你在飞书里交代的活做完了、在等你回答，助理的转告也会推到飞书。回复某张会话卡片、/new、项目群照旧直达会话。
