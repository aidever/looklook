LookLook desktop 1.77.2: the Feishu CLI installs the official way, Feishu replies read like a person wrote them, and opening sessions or the assistant no longer stalls.

- Feishu CLI: LookLook only checks whether it's installed, and installs it with Feishu's official command (the CLI and its skills together; Chinese setups use a China mirror). After that the assistant handles setup, sign-in and usage by following the official skills, and sends you a link to authorize in Feishu the first time. Fixes step 2 failing with "command not found: lark-cli".
- Feishu replies: one or two plain sentences, like a colleague would write, with just the result and who needs to do what. What the assistant does along the way is no longer posted to groups (it's folded into "Thinking" in private chats).
- Opening a session or switching to the assistant no longer waits a few seconds: the conversation shows right away and Claude Code / Codex reconnects in the background.
- Quoted messages no longer show tags like <p>.
- The assistant finds projects better: when a folder holds several repos it looks inside, and it fetches before saying a commit can't be found.
